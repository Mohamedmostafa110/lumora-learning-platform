## 📌 Project Overview

**Lumora Learning Platform** is an enterprise-grade Online Learning Platform (inspired by platforms like Udemy and EduHub). The platform bridges the gap between instructors and students by providing a seamless, interactive, and modern e-learning environment.

### 🌟 Key Capabilities

- **For Students:** Browse & filter courses, enroll in free & paid courses, track learning progress, watch video lessons with a custom UI player, take quizzes, earn automated PDF certificates with unique verification IDs, and share achievements on LinkedIn.
- **For Instructors:** Manage courses (CRUD), organize content into sections & lessons, upload video content securely, set pricing/discounts, build quizzes, and monitor revenue/enrollment statistics.
- **For Admins:** Platform-wide oversight, course review & approval workflow, user management, category management, and analytics dashboard (using Chart.js).

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** React.js, HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, Video.js, Progress.js
- **Backend:** C#, ASP.NET Core MVC / Web API (.NET 8/9), Entity Framework Core
- **Security & Auth:** ASP.NET Core Identity (Role-Based Access Control - RBAC)
- **Architecture:** N-Tier Architecture (`Web/API`, `Services`, `Data`)
- **Design Patterns:** Repository Pattern, Unit of Work, Strategy Pattern, Observer Pattern, Dependency Injection
- **Cloud & Storage:** Microsoft Azure App Service, Azure Blob Storage (Video Hosting), Azure CDN
- **Third-Party Integrations:** Stripe API (Payments), iTextSharp (PDF Certificate Generation)
